# 90일 실행계획

## 운영 리듬

- 월요일: 전주 실적 입력, 가정 업데이트, 이번 주 실험 선택
- 화~목요일: 콘텐츠·커뮤니티·B2B 실행
- 금요일: 전환 리뷰, 승자·패자·다음 행동 기록
- 매 2주: 채널 목표권수 재배분
- 매 4주: 출판사·저자·교육 운영 공동 리뷰

## 1~2주차 — 증거와 전환 기반 만들기

### 산출물

- Agent Build-or-not 결정 카드
- 문제정의 워크시트
- 모델·effort·컨텍스트 트러블슈팅 표
- 책 소개 랜딩 또는 보너스 등록 페이지
- 채널별 UTM 규칙과 실적 시트
- B2B 30권 패키지 1장 제안서

### 실험

1. LinkedIn/Instagram에서 `5회 반복 기준`과 `7분 중단 규칙` 비교
2. HR, PM, AI 자동화 커뮤니티별 제목 세 가지 테스트
3. 기존 수강생 중 동의자에게 결정 카드 사용성 인터뷰 5건

### 종료 조건

- 대표 리드 자산 1개 완성
- 전용 링크로 다운로드·서점 이동 측정 가능
- 상위 메시지 2개 선택

## 3~4주차 — Owned·커뮤니티 출시

### 실행

- 주 3회 실제 질문 기반 포스트
- 주 1회 뉴스레터 또는 긴 아티클
- 커뮤니티 무료 세션 2회
- 출판사와 3대 서점 상세페이지·테마전 제안
- Alumni에는 판매 공지보다 업데이트 자료와 오피스아워 제공

### 측정

- 포스트 → 결정 카드 다운로드
- 다운로드 → 서점 이동
- 웨비나 신청 → 참석 → 상담
- 동의 기반 후기·사례 확보

## 5~8주차 — B2B 집중

### 타겟 계정

- HR/L&D·조직문화 팀
- 사내 AX/DT 담당 조직
- 직무 커뮤니티 운영사
- 중소기업 협회·교육기관

### 실행

- 주 5개 계정 맞춤 제안
- 2주마다 공개 진단 세션 1회
- 30권 패키지 데모 3건 이상
- 파일럿 고객에는 전후 측정표 포함

### B2B 진단 질문

1. 현재 AI 교육의 종료점은 수강인가, 업무 변화인가?
2. 반복 업무 후보를 누가 어떤 기준으로 고르는가?
3. 모델 비용과 보안·승인 책임은 누가 관리하는가?
4. 실제로 바뀐 업무를 무엇으로 증명할 것인가?

## 9~12주차 — 승자 확대와 권위 채널

### 실행

- 전환이 검증된 메시지만 리타겟팅
- 동의받은 사례 2개를 케이스 스터디로 발행
- 사례와 체크리스트를 들고 유튜브·팟캐스트·기고 피칭
- 서점별 이동·보너스 등록·전체 판매 추이를 함께 검토
- 2차 인쇄 또는 추가 교육 패키지 의사결정

## 실험 로그 최소 필드

`날짜 / 채널 / 세그먼트 / 메시지 / 콘텐츠·오퍼 / 노출 / 유효행동 / 서점 이동 / 확인 판매 / 비용 / 판정 / 다음 행동`

## 중단 기준

- 같은 메시지로 3회 실행했는데 유효행동이 없으면 문구가 아니라 세그먼트·오퍼를 다시 봅니다.
- 조회는 높지만 서점 이동이 없으면 권위 콘텐츠로 분리하고 판매 예측에서 제외합니다.
- B2B 미팅은 많지만 견적 요청이 없으면 패키지 범위·가격·결재 근거를 수정합니다.
- 개인정보 동의가 불명확한 사례는 성과가 좋아도 외부 콘텐츠로 쓰지 않습니다.
