# AWAC 근거 기반 도서 판매 채널 전략

## 전략 한 문장

**책을 “AI 도구 설명서”로 팔지 않고, 내 업무를 Agent로 바꿀지 말지 판단하고 비용·품질을 통제하는 실행 운영체계로 판다.**

AWAC 1기의 실제 질문은 이 포지셔닝을 지지합니다. 참여자는 새로운 모델 소식에도 반응했지만, 행동을 만든 것은 `내 업무에 적용`, `5회 반복 기준`, `모델·effort 선택`, `멀티 Agent 비용`, `읽기 쉬운 결과`였습니다.

## 기존 성장모델 진단

기존 `AI_AX_도서_출판_그로스모델.xlsx`의 목표는 90일 1,000권입니다.

- 바텀업 예상: 690권
- 예상 부족: 약 310권
- 예상 달성률: 69%
- 강한 채널: HR/직무 커뮤니티 216권, 유료 광고 71권
- 큰 갭: 서점 140권, 유튜브/팟캐스트 117권, B2B 단체구매 65권, 저자 채널 52권

여기서 핵심은 약한 채널에 더 많은 희망치를 얹는 것이 아닙니다. AWAC에서 이미 반응이 확인된 `실무 문제 + 커뮤니티 + 코칭`을 앞세우고, 유튜브·PR은 이를 증명하는 사례가 쌓인 뒤 확장합니다.

## 우선 타겟과 오퍼

### 1. 실무자 — “내 일을 바꾸는 판단 기준”

- 대상: HR, PM/PO, 마케팅, AI 자동화 관심 직장인
- 문제: 무엇이든 Agent로 만들려다 시간·토큰을 낭비함
- 메시지: `5번 이상 반복하는 일만 Agent 후보로 올리세요.`
- 오퍼: 책 + Build-or-not 카드 + 문제정의 워크시트 + 모델 선택표
- 목표 행동: 샘플 챕터 다운로드 → 서점 이동 → 구매

### 2. 관리자·의사결정자 — “도구 배포를 성과로 바꾸는 운영체계”

- 대상: 팀장, CIO, HR/L&D, 조직문화·AX 담당자
- 문제: 교육과 라이선스는 샀지만 현업 업무가 변하지 않음
- 메시지: `성과의 단위는 수강 인원이 아니라 실제로 바뀐 업무입니다.`
- 오퍼: 책 30권 + 90분 강연 + 팀 문제정의 워크숍 + 관리자 측정표
- 목표 행동: 웨비나 참석 → 진단 미팅 → 단체구매

### 3. 개인 독자 — “AI 시대에도 스스로 문제를 정의하는 사람”

- 대상: 자기계발·커리어 독자, 취업·이직 준비자
- 문제: 도구는 많이 써봤지만 결과물이 경력 자산으로 남지 않음
- 메시지: `AI를 잘 쓰는 사람보다 무엇을 맡길지 판단하는 사람이 성장합니다.`
- 오퍼: 책 + 직무 결과물 예시 + 포트폴리오 변환 가이드
- 목표 행동: 콘텐츠 저장·공유 → 서점 상세 → 구매

## 판매 퍼널

```text
실제 질문 콘텐츠
  → 무료 결정 카드/샘플 챕터
    → 45분 온라인 진단 세션
      → 개인: 서점 구매
      → 팀: 30권 패키지 상담
        → 4주 AWAC형 사내 코호트
          → 동의받은 사례·추천사
            → 다음 커뮤니티/PR/미디어 확장
```

퍼널의 핵심은 책 구매 이후입니다. 책을 강연의 기념품으로 두지 않고, 모든 참여자가 같은 판단 언어를 갖게 하는 워크북으로 사용합니다.

## 채널별 역할

### P0. Owned: LinkedIn, Instagram, 뉴스레터, AWAC Alumni

- 매주 실제 질문 하나를 `상황 → 잘못된 선택 → 판단 기준 → 바로 쓰는 카드`로 발행
- 6대 콘텐츠 시리즈:
  1. Agent를 만들지 말아야 할 때
  2. 모델과 effort의 차이
  3. 7분 중단 규칙
  4. 뇌는 클라우드, 손은 로컬
  5. 멀티 Agent 4층 구조
  6. 읽기 쉬운 AI 결과물
- Alumni에는 판매 공지가 아니라 월 1회 오피스아워와 업데이트 자료를 먼저 제공
- 후기·사례는 명시적으로 동의한 사람만 외부 활용

### P0. HR/직무 커뮤니티

- 주제: `AI 교육을 해도 현업이 바뀌지 않는 이유` 또는 `1부서 1 Agent 전에 필요한 판단 기준`
- 형식: 45분 무료 세션 + 15분 Q&A + 진단표 다운로드
- 대상 커뮤니티를 HR/L&D, PM/PO, AI 자동화 세 그룹으로 나눠 문구를 바꿈
- 커뮤니티별 전용 UTM과 쿠폰을 사용해 서점 이동·구매를 구분

### P0. B2B 단체구매

- 패키지 A: 30권 + 90분 강연 + 워크시트
- 패키지 B: 50권 + 반일 문제정의 워크숍 + 관리자 리포트
- 패키지 C: 100권 + 4주 사내 AWAC + 전후 역량·적용 측정
- 제안서 첫 장에는 책 소개보다 AWAC 질문 4개와 운영 전후 변화를 배치
- 목표: 90일 안에 9개 계정과 진단 미팅, 평균 30권 이상 6건에 집중

### P0. 서점

- YES24: `AI 도입을 실제 성과로 바꾸는 판단 기준`
- 교보문고: `AI 시대 제품·조직·커리어의 공통 판단 기준`
- 알라딘: `AI 도구 수집을 넘어 결과를 만드는 실행 구조`
- 상세페이지에 체크리스트 미리보기와 QR 리드 자산을 연결
- 서점별 판매를 직접 추적하기 어렵다면 각 서점 전용 보너스 페이지로 이동을 측정

### P1. 유튜브·팟캐스트

- 면접왕 이형: AI 시대의 문제정의·커리어 결과물
- 커리어데이: 저자 커리어 전환과 현장 코칭 사례
- EO: “AI 제품을 만드는 것”과 “조직이 AI로 일하는 것”의 차이
- 티타임즈TV: 도구 도입이 성과로 이어지지 않는 조직의 구조
- 출연 제안은 책 목차보다 `AWAC에서 실제로 나온 질문 5개`와 독점 체크리스트를 중심으로 구성

### P1. 인플루언서·PR

- 30명 일괄 발송 대신 HR/L&D, PM/PO, 커리어, AI 자동화 각 5명에게 서로 다른 메시지로 시딩
- 게시 조건을 강요하지 않고, 게시율·링크 방문·서점 이동을 기록
- 기자·기고는 신제품 소식보다 `교육 이수에서 업무 변화로 성과 단위를 바꾸는 법`을 피칭

### P2. 유료 광고

- 콜드 브로드 캠페인은 마지막
- 무료 결정 카드 열람자, 웨비나 참석자, 서점 이동자만 리타겟팅
- 광고 문구는 Owned에서 저장·클릭·다운로드가 검증된 상위 2개만 사용

## 성공 지표

### 최종 지표

- 확인 판매권수
- B2B 단체구매 권수와 계정 수
- 90일 누적 매출과 권당 판촉비

### 선행 지표

- 무료 자산 다운로드 수와 채널별 전환율
- 웨비나 신청·참석·상담 전환율
- 서점 이동 클릭과 전용 보너스 등록
- B2B 진단 미팅, 제안서, 수주 전환율
- 동의받은 사례·후기 수

### 판단 규칙

- 콘텐츠 3개 중 2개가 기준 클릭률을 넘으면 같은 메시지를 확대합니다.
- 커뮤니티 세션 2회에서 참석→상담 전환이 재현되면 B2B 예산을 늘립니다.
- 시딩은 게시율보다 서점 이동과 확인 판매를 우선합니다.
- 판매 기여가 불명확한 조회수는 성과로 계산하지 않습니다.
- 매주 실제값으로 기존 성장모델의 실행률·유효행동·구매율을 교체합니다.

## 리스크와 방어선

- **과장된 자동화 약속:** “무엇이든 된다” 대신 자동화하지 않을 기준을 함께 제시합니다.
- **제품 정보의 빠른 노후화:** 모델명·가격보다 변하지 않는 선택 원칙을 본문에 두고 최신 정보는 웹 부록으로 분리합니다.
- **참여자 개인정보:** 얼굴, 실명, 채팅 캡처는 동의 없이는 마케팅에 쓰지 않습니다.
- **채널 착시:** 조회·좋아요와 판매를 분리하고 UTM·쿠폰·보너스 등록으로 간접 기여를 추적합니다.
- **강의가 책을 잠식:** 강의는 답을 대신 주는 상품이 아니라 책의 프레임을 팀 업무에 적용하는 서비스로 설계합니다.

## 의사결정

1. 첫 4주는 미디어 섭외보다 Owned·커뮤니티·B2B 리드 자산 완성에 집중합니다.
2. 캠페인 대표 메시지는 `AI를 잘 쓰는 법`이 아니라 `무엇을 AI에게 맡길지 판단하는 법`으로 통일합니다.
3. 대표 리드 자산은 `Agent Build-or-not 결정 카드`로 시작합니다.
4. B2B 대표 상품은 `책 30권 + 90분 강연 + 문제정의 워크시트`로 단순화합니다.
5. AWAC 사례는 익명 통찰로만 사용하고, 개별 후기·사진은 동의 확보 후 별도 운영합니다.
