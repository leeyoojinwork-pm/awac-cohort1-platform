## V2에서 바뀐 점

| 1기에서 확인한 문제 | V2 설계 |
|---|---|
| 노션·계정·권한 문제 | 수업 24시간 전 4단계 프리플라이트 |
| 과제 범위가 모호함 | 현재/반복/원하는 변화/제약 4칸 문제정의 |
| 한 번 쓸 일도 Agent로 만들지 고민 | 1·2·5회 반복 기준과 Build-or-not 카드 |
| 멀티 Agent 비용·실행 정지 | 모델 라우팅, 7분 중단 규칙, 복구 순서 |
| 결과가 어렵고 검증이 불안함 | 팩트체크 게이트, ASD-STE100, 출력 형식 선택 |
| 수료 후 지속 사용이 어려움 | 30일 재사용 실험과 Alumni 오피스아워 |

## 설계 원칙

1. 설명 전에 선택 기준을 줍니다.
2. 매주 하나의 파일을 완성하고 다음 주 입력으로 씁니다.
3. 실행하지 않은 결과를 성공 사례로 기록하지 않습니다.
4. 모델명·가격보다 오래가는 판단 원칙을 가르칩니다.
5. 자동화 범위와 사람의 승인 지점을 함께 설계합니다.
