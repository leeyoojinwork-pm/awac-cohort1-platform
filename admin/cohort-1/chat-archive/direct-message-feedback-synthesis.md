# AWAC 1기 개인톡 만족도·평가 종합

## Executive summary

AWAC 표기가 붙은 1:1 대화방 15개를 확인했습니다. 이 중 9개 대화방에서 과정 종료 후의 명시적 만족도·평가가 확인됐고, 4개에서는 시작 전 기대·참여 장벽·운영 적합성에 관한 보조 신호가 확인됐습니다. 2개 대화방에는 과정 평가 관련 발언이 없었습니다.

긍정 평가는 단순한 “재미있었다”보다 다음 변화에 집중됐습니다.

1. 초보자도 따라갈 수 있는 강의덱과 준비된 진행
2. 막연했던 Agent 개념을 실제 업무·면접·포트폴리오에 연결한 경험
3. 도구 사용을 넘어 문제 발굴, 요구사항, `why/how`를 판단하는 구조
4. 심화과정·다른 클래스·후속 콘텐츠에 다시 참여하려는 의향

가장 구체적인 개선 의견은 한 참여자에게서 나왔습니다. 팀별 속도·직무가 달라 수업 중 개인 프로젝트 실습이 부담스러웠고, 공통 사례로 이론을 익힌 뒤 개인 적용은 과제로 수행하며 1:1 피드백을 늘리는 편이 낫다는 제안이었습니다. 한 명의 의견이므로 전체 선호로 일반화하면 안 되지만, 운영 설계를 바꿀 만큼 구체적인 증거입니다.

## 조사 범위와 방법

- 확인일: 2026-10-11
- 자료: 카카오톡 대화방 이름이 `AWAC_`로 표시된 1:1 대화방 15개
- 명시적 수료 후 평가: 9개 대화방
- 보조 신호: 4개 대화방
- 평가 문장 없음: 2개 대화방
- 코딩 단위: 교육 품질, 학습 변화, 실제 적용, 정서적 경험, 개선 제안, 재참여 의향
- 공개 처리: 실명·개인 사정·개인 링크를 제거하고 의미만 익명 요약
- 원문: 공개 저장소 밖의 비공개 관리자 아카이브에 보존

개인톡은 자발적 후기와 운영진이 요청해 받은 답변이 섞인 질적 자료입니다. 응답률이나 전체 만족도를 대표하는 설문으로 해석하지 않습니다.

## 핵심 테마

### 1. 만족의 근거는 “쉽다”가 아니라 “따라서 써봤다”였다

초보자 친화적 강의덱이라는 평과 함께, 실제로 여러 업무에 AI를 적용하고 수치 검토 방식을 바꾸었다는 경험이 나타났습니다.

**의미:** 쉬운 설명은 단독 가치가 아니라 첫 실행까지 이어질 때 만족을 만듭니다.

**기회:** 모든 개념 슬라이드에 `복사 가능한 첫 행동`, `정상 결과`, `실패 시 다음 행동`을 붙입니다.

### 2. 가장 강한 성과는 Agent 제작보다 관점 전환이었다

참여자들은 Agent를 막연한 자동화로 보던 상태에서 문제 발굴, 업무 흐름, 요구사항, 사람의 의도를 먼저 보는 상태로 이동했습니다.

**의미:** AWAC은 도구 강의보다 업무 설계 교육으로 포지셔닝하는 편이 실제 경험과 일치합니다.

**기회:** 강의의 모든 실습을 `문제 → 판단 → 실행 → 검수` 네 단계로 반복합니다.

### 3. 커리어 결과물이 학습 전이를 증명했다

면접 준비, 포트폴리오, 이직 후 활용 기반, 직무 프로젝트 구조화가 만족 이유로 등장했습니다.

**의미:** 수료 산출물은 작동하는 데모뿐 아니라 고용주에게 설명 가능한 판단 근거여야 합니다.

**기회:** `기업이 보는 좋은 AI 활용` 기준과 포트폴리오 스토리 카드를 4주차에 추가합니다.

### 4. 팀 활동은 목적과 속도가 맞을 때만 가치가 난다

직무·상황·작성 속도가 다른 상태에서 미완성 생각을 공유하는 활동은 한 참여자에게 큰 인사이트를 주지 못했습니다. 반면 강사의 사례와 개별 대화는 생각을 확장하는 데 도움이 됐습니다.

**의미:** 팀 활동 자체가 학습 장치는 아닙니다. 공통 입력, 명확한 역할, 비슷한 속도 또는 결과 목표가 있어야 합니다.

**기회:** 공통 사례 실습 후 `개인 집중 / 직무 유사 페어 / 확장 트랙` 중 하나를 선택하게 합니다.

### 5. 1:1 피드백은 부가 서비스가 아니라 핵심 학습 장치다

개별 대화에서 문제 정의와 해결 방향을 짚어준 답변이 생각을 트이게 했다는 평가가 있었습니다.

**의미:** 자유 질문 시간을 남겨두는 것만으로는 부족합니다. 모든 참여자에게 짧더라도 보장된 피드백 슬롯이 필요합니다.

**기회:** 주차마다 4분 마이크로 클리닉을 순환하고, 전체 기록에는 개인 정보를 뺀 판단 기준만 남깁니다.

### 6. 재참여 의향은 “같은 과정 한 번 더”보다 상위 난이도를 향했다

여러 참여자가 심화과정, 다른 클래스, 후속 콘텐츠에 다시 참여하고 싶다는 뜻을 밝혔습니다.

**의미:** Alumni 운영은 신기능 소개보다 실제 실행 로그와 실패를 다루는 상위 트랙이 적합합니다.

**기회:** `Foundation`과 `Studio`를 분리합니다. Foundation은 단일 Agent와 검수, Studio는 멀티 Agent·라우팅·운영비·포트폴리오 방어를 다룹니다.

## 참여자 세그먼트

| 세그먼트 | 필요 | 과정 설계 |
|---|---|---|
| AI 초보자 | 용어보다 첫 실행과 정상 상태 | 주석 많은 덱, 공통 예제, 단계별 체크 |
| 취업·이직 준비자 | 프로젝트를 설명 가능한 포트폴리오로 전환 | 문제·판단·근거·검수 스토리 카드 |
| 현업 적용자 | 업무 흐름과 비용·품질 통제 | 실제 데이터 없이도 구조를 검증하는 PoC |
| 깊게 생각하는 학습자 | 제한 시간 압박 없이 정리 | 개인 집중 트랙, 사전 작성, 비동기 피드백 |
| 상위 학습자 | 단일 Agent 이후 운영 난이도 | 멀티 Agent, 모델 라우팅, 실패 복구, 로그 클리닉 |

## 권고안

### P0 · 다음 운영 전에 반영

1. 팀을 임의로 섞지 않고 직무 결과·속도·목표로 매칭합니다.
2. 수업 중 실습은 공통 입력으로 시작하고 개인 적용은 과제로 분리합니다.
3. 주차별 참여자 1인당 4분 피드백 슬롯을 확보합니다.
4. 4주차에 `기업이 보는 좋은 AI 활용`과 포트폴리오 스토리 카드를 추가합니다.
5. 마지막 회차 결석자를 위한 비동기 발표 열람·피드백 경로를 둡니다.

### P1 · 2기에서 검증

1. `개인 집중 / 직무 유사 페어 / 확장` 선택형 트랙을 실험합니다.
2. 강의·사례 40분, 공통 실습 35분, 개인 적용 25분, 피드백 20분 비율을 기록합니다.
3. 시작·종료 설문에 심리적 장벽, 실제 적용 업무 수, 재사용 의향을 같은 문항으로 측정합니다.

### P2 · 수료 후 확장

1. Foundation 수료자를 위한 Studio 트랙을 엽니다.
2. Alumni 오피스아워를 실행 로그·실패 복구·포트폴리오 방어 중심으로 운영합니다.
3. 30일 후 실제 재사용, 시간 변화, 유지·수정·중단 결정을 수집합니다.

## 한계

- 개인톡은 운영진의 질문에 답한 후기와 자발적 후기가 섞여 있습니다.
- 평가를 남긴 9명이 전체 참여자 25명을 대표하지 않습니다.
- 가장 구체적인 부정적 운영 피드백은 한 명의 경험입니다.
- 만족 표현은 확인됐지만 시간 절감·품질 향상 수치는 대부분 측정되지 않았습니다.
- 공개 홍보 문구나 추천사로 사용하려면 발언자별 별도 동의가 필요합니다.
